# Интерфейс ядра лабораторных работ

`Dataset` загружает CSV и выполняет предобработку. `ModelMatrix` хранит
матрицу признаков и именованные отклики; `split` переставляет их совместно.
`DatasetMatrix` предоставляет строки как `span`: представление не владеет
памятью и действительно только пока существует неизменённая матрица.

## Модели второй работы

`IModel` задаёт `fit` и `predict`. `kNNBase` хранит копию обучающей выборки,
владеет метрикой через `unique_ptr` и ищет соседей максимальной кучей.
`kNNRegressor` вычисляет среднее, `kNNClassifier` суммирует голоса.
Общая база исключает дублирование поиска; виртуальный `consolidate`
задаёт различие моделей. Метрика — стратегия, переданная извне.

`Weighting::Uniform` — равные веса. `Weighting::Distance` — обратные расстояния.
В реализации веса масштабированы на минимальное расстояние: общий множитель
не меняет среднее и победителя голосования, но предотвращает переполнение
обратной величины. При нулевых расстояниях учитываются только совпавшие
соседи из выбранных k: среднее для регрессии, голосование для классификации.
Ничьи расстояний разрешаются по индексу строки, ничьи классов — по меньшей метке.
Классы представлены конечными числовыми метками; преобразование в unsigned
не выполняется. Политика весов задана enum: для двух фиксированных режимов
отдельная иерархия не требуется.

Для одного запроса поиск занимает O(n d + n log k), память поиска O(k).
Модель отдельно хранит O(n d) данных и O(n) откликов. Возвращаемый массив
предсказаний занимает O(m), где m — число запросов.

`fit` требует непустые конечные данные RowMajor, один отклик на строку и
1 <= k <= n. `predict` требует успешный `fit` и то же число признаков.
Пустой набор запросов допустим. Ошибки ядро сообщает исключениями;
приложение ловит их по const-ссылке и выводит `what()` с местом обнаружения.

## Сохранение

Один бинарный файл: size_t cols, size_t rows, Layout; для каждого имени
size_t длина и байты; rows*cols значений double; size_t число откликов.
Для каждого отклика: строка имени, size_t тип, size_t число значений и double;
size_t число категорий, затем для каждой строка и int код.
Строка всегда записывается как size_t длина и байты без завершающего нуля.
Формат локальный: зависит от ABI и порядка байтов, не имеет версии и checksum.
Он предназначен для собственных файлов этой сборки, не для недоверенных данных.

## Ограничения

Рабочий путь — RowMajor. ColumnMajor не реализован как полноценный способ
индексации. Предобработка демонстрационного датасета выполняется до split;
для оценки качества без утечки нужна отдельная обучаемая предобработка.
Документация и тесты не означают, что эти ограничения исправлены.
